# Gym and Fitness Chatbot

## Features
- Exercise recommendation
- Intent recognition
- Entity extraction
- Rasa dialogue management
- User feedback collection

## Running the System

1. Activate environment

2. Start action server:
rasa run actions

3. Start Rasa API:
rasa run --enable-api

4. Run Streamlit:
streamlit run app.py
